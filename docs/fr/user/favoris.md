# Gestionnaire de Ressources (Favoris)

Arrêtez de vous noyer dans les onglets ouverts de votre navigateur. Le Gestionnaire de Ressources est votre bibliothèque centrale pour la documentation, les outils et les liens de projet.

## 📁 Collections
Organisez vos ressources en catégories logiques :
- **Navigation :** Utilisez les onglets de haut niveau pour basculer entre les collections (ex: "IA", "Docs", "Client X").
- **Gestion :** Cliquez sur l'icône **Paramètres** à côté des onglets pour créer, renommer ou supprimer des collections.
- **Non assignés :** Tout favori sans collection apparaîtra automatiquement dans l'onglet "Non assigné".

## 📌 Barre d'Épinglés
La barre "ÉPINGLÉS" en haut de la liste des favoris est votre zone d'accès rapide :
- **Contextuelle :** Elle filtre intelligemment selon la collection que vous consultez actuellement.
- **Spécifique au Projet :** Si vous associez un favori à un projet, il apparaîtra prioritairement lorsque vous filtrez par ce projet.
- **Bascule :** Cliquez sur l'icône **Étoile** de n'importe quel favori pour l'épingler ou le désépingler de la barre.

## 🤖 Métadonnées Automatiques
Lorsque vous ajoutez une nouvelle URL :
- **Récupération Auto :** Le tableau de bord tente de récupérer automatiquement le titre et la description du site web.
- **Favicons :** Les favicons haute résolution sont rendus via un service de proxy professionnel pour rendre les liens facilement identifiables.

## 📤 Import & Export
Partagez votre bibliothèque ou déplacez-la entre machines en utilisant les icônes **Télécharger** et **Charger** dans l'en-tête. Les données sont traitées au format JSON standard.
