# Resource Manager (Bookmarks)

Stop drowning in open browser tabs. The Resource Manager is your central library for documentation, tools, and project links.

## ðŸ“ Collections
Organize your resources into logical categories:
- **Navigation:** Use the top-level tabs to switch between collections (e.g., "AI", "Docs", "Client X").
- **Management:** Click the **Settings** icon next to the tabs to create, rename, or delete collections.
- **Unassigned:** Any bookmark without a collection will automatically appear in the "Unassigned" tab.

## ðŸ“Œ Pinned Bar
The "PINNED" bar at the top of the bookmarks list is your quick-access area:
- **Context-Aware:** It intelligently filters based on the collection you are currently viewing.
- **Project Specific:** If you associate a bookmark with a project, it will prioritize appearing when you filter by that project.
- **Toggling:** Click the **Star** icon on any bookmark to pin/unpin it from the bar.

## ðŸ¤– Automated Metadata
When you add a new URL:
- **Auto-Fetch:** The dashboard attempts to automatically scrape the website's title and description.
- **Favicons:** High-resolution favicons are rendered using a professional proxy service to make links easily identifiable.

## ðŸ“¤ Import & Export
Share your library or move it between machines using the **Download** and **Upload** icons in the header. Data is handled as standard JSON.
